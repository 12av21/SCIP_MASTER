5. API Architecture
All endpoints are hosted under /api/* with Bearer JWT token verification:
Method	Endpoint	Access Level	Description
GET	/api/health	Public	System status, database health, AI pipeline check
POST	/api/auth/register	Public	Registers user, validates data, hashes password with bcrypt
POST	/api/auth/login	Public	Authenticates credentials, logs audit, issues JWT token
GET	/api/auth/me	Authenticated	Retrieves current authenticated session
POST	/api/auth/demo-switch	Public / Eval	Switches test persona for evaluator walkthrough
GET	/api/reports	Authenticated	Retrieves reports (supports myOnly, category, status filters)
POST	/api/reports	Citizen / Officer	Submits report, triggers TF-IDF NLP pipeline & clustering
GET	/api/reports/:id	Authenticated	Returns report details with full AI analysis & similarity links
GET	/api/incidents	Authenticated	Lists incidents with category, priority, and status filters
POST	/api/incidents	Officer / Admin	Creates or confirms an incident from clustered reports
PATCH	/api/incidents/:id	Officer / Auth	Updates review status, priority, or human notes
POST	/api/incidents/:id/assign	Authority / Admin	Dispatches incident to specific department & officer
POST	/api/incidents/:id/resolve	Officer / Auth	Submits final work order resolution and remediation notes
GET	/api/intelligence/clusters	Officer / Auth	Returns real-time spatio-temporal DBSCAN clusters
GET	/api/intelligence/trends	Authenticated	Returns category volumes, recurrence rates, and KPIs
POST	/api/intelligence/agent	Officer / Auth	Runs SCIP multi-tool agent on natural language queries
GET	/api/admin/users	Admin	Lists registered users and department associations
GET	/api/admin/audit-logs	Authority / Admin	Returns immutable audit log records with module filters
POST	/api/tests/run	Public / Eval	Runs automated 22-point system verification suite
POST	/api/seed	Admin / Eval	Resets database to realistic municipal market incident data
6. AI & Machine Learning Architecture
The core intelligence pipeline uses deterministic, explainable algorithms rather than black-box models:
code
Code
Raw Report Submission (Text + Category + GPS + Timestamp)
                    │
                    ▼
   [ Stage 1: Text Normalization & Stemming ]
     (Porter Stemming, Stopword Removal, 2-gram Collocations)
                    │
                    ▼
   [ Stage 2: Supervised TF-IDF Vectorization ]
     (Inverse Document Frequency across Municipal Corpus)
                    │
                    ▼
   [ Stage 3: Cosine Similarity Matrix ]
     (Pairwise dot product against recent observations: threshold ≥ 0.25)
                    │
                    ▼
   [ Stage 4: Duplicate & Relationship Detector ]
     (Calculates duplicate probability & shared keyword overlap)
                    │
                    ▼
   [ Stage 5: Spatio-Temporal DBSCAN Clustering ]
     (Haversine Distance ≤ 750 meters + Time Window ≤ 72 hours)
                    │
                    ▼
   [ Stage 6: Explainable Risk Scoring Engine ]
     (Score 0–100 decomposed into Severity, Density, Recurrence, Affected Area)
                    │
                    ▼
   [ Stage 7: Responsible AI Gatekeeper ]
     (Synthesizes Potential Incident Hypothesis → Requires Human Officer Review)
The Three Separation Principles
Community Report = Observation: Raw citizen ground signal.
AI Incident = Analytical Interpretation: Correlation hypothesis with confidence metrics.
Administrative Decision = Human Review: Accountable officers review evidence, confirm or dismiss hypotheses, and dispatch work orders.
7. Authentication Architecture
Password Security: Passwords are salted and hashed using bcryptjs with cost factor 10.
Session Tokens: Cryptographically signed JSON Web Tokens (HS256) containing user ID, email, and role, expiring in 7 days.
Header Transport: Client sends Authorization: Bearer <token> on all API calls.
Audit Logging: Successful and failed login attempts are logged in the AuditLogs table with client IP, timestamp, and email.

14. Known Limitations & Future Improvements
Offline Sync (PWA): Field officers working in network dead-zones can queue inspection photos for background upload upon reconnection.
Multilingual NLP: Expand the English stopword and stemming dictionary to support regional Indian languages (Hindi, Marathi, Tamil, etc.) using Indic-NLP tokenization.
IoT Sensor Grounding: Ingest real-time municipal telemetry (water level sensors in storm drains, smart grid current readings) as continuous observation signals alongside citizen reports.
